# Anvil IDE 0.0.2~pre1

> **Pre-release.** This is the 0.0.2 personalization and localization work,
> packaged for early installation and testing. The Codewhale connector
> (IMP-003) and ROS 2 environment resolution (IMP-005) are **not** included.
> Build/run, debugging, the integrated terminal, Git write operations, plugins,
> and AI remain out of scope.

- **Package:** `anvil_0.0.2~pre1-1_amd64.deb`
- **Upstream version:** 0.0.2
- **Date:** 2026-11-16
- **Platform:** Ubuntu 24.04 LTS, x86_64
- **License:** Apache-2.0

The `~pre1` suffix is Debian's pre-release convention: apt sorts this package
before the final `0.0.2-1`, so installing it now does not block a later
upgrade.

## Install

```bash
sudo apt install ./dist/anvil_0.0.2~pre1-1_amd64.deb
anvil /path/to/your/project
```

apt pulls the recommended runtime packages (`bubblewrap`, `clangd-18`,
`gdb`/`lldb`, `git`, `cmake`, `ninja-build`). Language intelligence stays
disabled, with an explanation in the status bar and Security Status dialog, if
clangd or bubblewrap is missing.

To remove completely:

```bash
sudo apt remove --purge anvil
```

## What is new since 0.0.1

- **Russian UI localization (IMP-001).** Settings → Appearance → Display
  language: `Automatic (system)`, English, Русский. Switching is instant, the
  choice persists, and `Automatic` follows the system locale (`ru_RU.UTF-8` →
  Russian, otherwise English). Diagnostics and logs stay in the language of the
  underlying tool.
- **Theme selection (IMP-002).** Anvil Dark (default), Anvil Light, Anvil High
  Contrast, and `Automatic` system following. Monaco themes switch with the
  app. All UI text pairs pass WCAG AA (4.5:1) in every theme.
- **Font selection (IMP-004).** UI and editor font family, UI size 11–18 px,
  editor size, line height (compact/normal/relaxed), and ligatures. Installed
  families are enumerated from fontconfig; an unknown or missing family falls
  back safely.
- **Version single-sourcing.** `core/include/anvil/version.hpp` is canonical;
  CMake, the shell, the UI manifest, Debian metadata, and the SBOM derive from
  it, and `scripts/check-version.sh` fails the build if a copy drifts.

## Known limitations

- Startup (~0.85 s) and full-stack memory (> 800 MiB with clangd) still miss the
  targets; performance work is scheduled for 0.0.3.
- Native GTK file dialogs follow the system locale, not the in-app language.
- No build/run, debugger, terminal, Git staging/commit, plugins, or AI.
- The APT repository in `dist/` is signed with a demonstration key and must not
  be used for public distribution.
- `lintian` was unavailable in the reference environment; structural checks and
  a GUI smoke test were used instead.
- The UI is a single bundle because `file://` cannot reliably load lazy ES
  module chunks; a custom URI scheme is planned.
